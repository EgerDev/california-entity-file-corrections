# California Entity File — corrections only

This repository is a **public issue tracker** for factual corrections to *The California Entity File*, a local preview of a California business-entity calendar.

It is **not** a filing product. It is **not** launched. Do not pay anyone here. Do not send entity names, SOS file numbers, or payment details unless you choose to.

## How to file a correction

1. Open a new issue.
2. Keep the pre-filled Fact ID and page if you have them.
3. Quote the product line that is wrong.
4. Paste the official URL we should read.

Correction-attribution rule: no correction without quoting the exact line being corrected.
